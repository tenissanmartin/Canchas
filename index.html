?¿Cómo funciona este panel?▾
  1. 1Cada 10 minutos consulto una app del tiempo (Open-Meteo) para ver si está lloviendo o si llovió hace poco en Villa Raffo.
  2. 2Si hay lluvia, miro las cámaras del club y comparo cómo está el polvo de ladrillo con fotos de las canchas secas y con casos anteriores. Para eso uso un sistema entrenado con inteligencia artificial.
  3. 3Según lo que veo, marco cada cancha como habilitada, húmeda (consultá en el club) o no habilitada (húmeda, con charcos o inundada). Antes de marcar una cancha como no habilitada lo confirmo en una segunda revisión; mientras tanto figura como húmeda. Si está lloviendo, ninguna figura como habilitada. Cuando la cancha se seca, vuelve sola a habilitada.
  4. 4Las imágenes de las cámaras no se publican: solo se usan para ver el estado de las canchas.
Estoy en fase de prueba, así que puedo equivocarme. Este panel es orientativo: ante la duda, consultá en el club antes de ir. La decisión final sobre si una cancha se puede usar es siempre del club.
